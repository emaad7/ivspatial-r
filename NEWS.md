# ivspatial 1.0.0

* First release. Same procedure, defaults and output as the Python package
  `ivspatial` 1.0.0 (PyPI): `spatial_test()` (combined test C4, data-driven
  resolution, spatial lags), the neighbourhood graphs (`knn_graph()`,
  `delaunay_graph()`, `distance_band_graph()`, `lattice_graph()`,
  `lattice_from_indices()`, `polygon_graph()`, `graph_from_edges()`,
  `graph_from_neighbors()`, `lag_graph()`, `build_graph()`),
  `screen_variables()`, `residual_test()`, `local_features()`, `map_local()`,
  `null_limit()`, `reference_table()`, `read_sites()`, `read_polygons()` and
  the graphical interface `ivspatial_app()`.
